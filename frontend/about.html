About the Project

AI-powered civic
complaint management

A full-stack platform that uses machine learning to automatically classify citizen complaints and route them to the right government department.

What is this?

Explainable AI for Civic Complaint Classification

This system allows citizens to submit complaints about civic issues — potholes, sanitation, water leaks, noise, and more. An AI model then reads the complaint and automatically assigns it to the correct city department.

Admins at each department can log in, view only their department's complaints, update statuses, and mark issues as resolved.

🤖

BERT-based Classification

A fine-tuned sentence transformer model reads complaint descriptions and predicts the responsible department.

📍

Location-Aware Priority

GPS coordinates are used with the Overpass API to measure area density and assign complaint priority scores.

🛡️

Role-Based Access

Citizens, department admins, and superadmins each have tailored views and permissions.

Tech Stack

Built with modern technologies

🐍

Flask + Python

RESTful backend API handling authentication, complaint submission, and ML model inference.

🧠

Sentence Transformers

BERT-based model (all-MiniLM-L6-v2) encodes complaint text for department classification.

🗄️

SQLite + SQLAlchemy

Lightweight relational database storing users, complaints, images, and videos.

🌐

Vanilla JS + HTML

Pure frontend with no framework — fast, lightweight, and easy to deploy anywhere.

📊

Scikit-learn

TF-IDF + Logistic Regression pipeline for hybrid priority classification alongside rule-based matching.

📍

Overpass API

Counts points of interest near complaint locations to determine area density for priority scoring.
